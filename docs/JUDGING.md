Open [Zcode](https://zcode-marketplace.pages.dev/browse) in a fresh browser. Gemini interpretation, the approved catalog, the Repo Passport and the free Inspect edition require no development credentials.

1. Enter this buyer brief in the top search box. “Our vendor CSVs repeat order IDs and sometimes put text in the total column. I need to catch both when the network is down, and reuse those checks on the next import. I can spend under $20 once.”
2. Select **Interpret with Gemini**. Check the original wording under each requirement. Change the upfront ceiling or a priority, then select **Find matching releases**. Its row is a **Near match**, and the contradicted capability links to the specific release finding.
3. Open [Column Desk Inspect](https://zcode-marketplace.pages.dev/release/column-desk-inspect) and use **Download sample ZIP** or [open the working tool](https://zcode-marketplace.pages.dev/samples/column-desk/inspect/index.html). Try the synthetic example, or choose a UTF-8 CSV. The tool processes the file in the browser. The verified ZIP SHA-256 is `3e326d818e0671b04a6f153faf8be63f4d458ca6bc3ebb010cf25b8353b6908f`. To run it from source, extract the ZIP, run `npm ci --offline` and `npm start`, then open [port 4173](http://127.0.0.1:4173/).
