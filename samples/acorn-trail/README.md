# Acorn Trail

Acorn Trail is a small original browser game and the public, redistributable verification sample for the marketplace. Its art is drawn in the browser from source.

1. Extract this ZIP into a new folder.
2. In the folder, run `npm ci --offline` with Node.js 24 and npm.
3. Run `npm start`.
4. Visit `http://127.0.0.1:4173`. Press Enter to begin. Use the arrow keys or WASD to collect three acorns and reach the camp at the right edge. On touch screens use the direction buttons.

The app has no runtime dependencies or API keys. Stop the server with Ctrl+C. Use a different free port by setting `PORT` before starting the server.

This sample is MIT licensed. It includes no external artwork, music, fonts or dependencies.
